How to Compress an Image to 100KB

Learn how to reduce an image to under 100KB while keeping it clear and suitable for websites, forms, and other online uses.

Updated August 2026 · 6 min read

In this guide

A 100KB image limit is common on online forms, application portals, and websites. In many cases, you can reach this limit by adjusting the image dimensions, choosing the right format, and applying suitable compression.

What Does 100KB Mean?

A 100KB limit refers to the size of the image file, not its width or height.

Even two images with the same dimensions can have different file sizes. The final size depends on factors such as the image format, content, and compression settings.

Choose the Right Format

Choosing the right image format can make it easier to reduce the file size while keeping good quality.

  • JPG is usually a good choice for photographs.
  • PNG is useful for graphics, illustrations, and images that need transparency.
  • WebP can provide smaller file sizes and is a useful option for websites that support the format.

Resize Large Images

If an image is much larger than the size it needs to be displayed, reducing its dimensions can significantly lower the file size.

Tip: Keep a copy of the original image before resizing or compressing it so you can use it again if needed.

A Simple Image Compression Workflow

  1. Start with the original image.
  2. Check the image dimensions and current file size.
  3. Resize the image if its dimensions are larger than necessary.
  4. Choose an appropriate image format.
  5. Apply compression gradually until you reach the desired size.
  6. Download the compressed image and check its quality before using it.

How to Keep the Image Clear and Readable

The smallest possible file size is not always the best choice. If your image contains text, documents, or screenshots, make sure the important details remain clear and readable after compression.

For photographs, check faces, edges, and fine details carefully. If the image looks too blurry or shows visible compression artifacts, slightly increase the quality and compress it again.

Common Mistakes to Avoid

Using Too Much Compression

Very low quality settings can make an image look blurry or distorted, even if they produce a much smaller file.

Keeping Unnecessarily Large Dimensions

An image that is 4000 pixels wide is often much larger than necessary for an online form or website. Resize the image based on how and where it will be used.

Not Checking the Final File Size

Always check the size of the downloaded image instead of assuming it meets the required limit. This is especially important when a website has a strict 100KB limit.

Final Checklist

  • Make sure the final image is under 100KB.
  • Confirm that the image opens and displays correctly.
  • Check that important details are still clear and visible.
  • Make sure you are using the appropriate file format.
  • Keep a safe copy of the original image.

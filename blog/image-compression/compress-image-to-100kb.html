How to Compress an Image to 100KB

Learn how to reduce an image below a 100KB file-size limit while keeping the result clear and suitable for online use.

Updated August 2026 · 6 min read

In this guide

What does 100KB mean? Choose the right format Resize oversized images Compression workflow Keep the image readable Common mistakes Final checklist

A 100KB image limit is common on online forms, application portals and websites. Fortunately, most images can be reduced to this size with the right combination of dimensions, format and compression.

What Does 100KB Mean?

100KB describes the size of the image file, not its width or height.

Two images with exactly the same dimensions can have very different file sizes because their format, image content and compression settings can differ.

Choose the Right Format

Selecting an appropriate format can make compression much easier.

  • JPG is generally suitable for photographs.
  • PNG works well for graphics and transparency.
  • WebP can be efficient for supported websites.

Resize Oversized Images

If the original image is much larger than the size at which it will actually be displayed, reducing its dimensions can significantly reduce the file size.

Tip: Always keep a copy of the original image before resizing or compressing it.

A Simple Compression Workflow

  1. Start with the original image.
  2. Check its current dimensions and file size.
  3. Resize it if it is unnecessarily large.
  4. Select a suitable image format.
  5. Apply moderate compression.
  6. Download and check the final file.

How to Keep the Image Readable

The smallest possible file is not always the best file. If the image contains text, documents or screenshots, make sure the text remains readable after compression.

For photographs, inspect faces, edges and fine details. If the image looks noticeably blurry or contains compression artifacts, increase the quality slightly and try again.

Common Mistakes

Using extreme compression

Extremely low quality settings can make an image look damaged even when the file size is very small.

Keeping unnecessary dimensions

A 4000-pixel-wide image is often unnecessary for an online form. Resize it according to its intended use.

Forgetting to check the final file size

Always verify the downloaded file rather than assuming it is below the required limit.

Final Checklist

  • The final image is below 100KB.
  • The image opens correctly.
  • Important details remain visible.
  • The correct file format is being used.
  • The original image is safely stored.

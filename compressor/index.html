IMAGE COMPRESSION

What Is Image Compression?

Image compression reduces the amount of data stored in an image so that the resulting file can be smaller. Smaller image files can be easier to upload, share, store and use on websites.

The amount of reduction depends on the image itself, its dimensions, the file format and the compression settings you choose.

Format Best For Consideration

FAQ

Frequently Asked Questions

What image formats can I compress?

You can upload JPG, PNG and WEBP images.

Can I compress an image to 50KB?

You can enter 50KB as the target file size. The final size is approximate because image content, dimensions and format affect the resulting file.

Can I resize an image?

Yes. You can specify maximum width and height. The image maintains its original aspect ratio.

Which format should I choose for photographs?

JPG and WEBP are generally useful choices for photographs when reducing file size is important.

Why can a compressed image sometimes be larger?

An image that is already highly optimized may become similar in size or even larger after being re-encoded.
